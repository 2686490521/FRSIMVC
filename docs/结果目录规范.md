# 实验结果目录规范

从 2026-09-17 起，所有实验输出必须保存在各自方法代码目录的 `results/` 下，不再在代码根目录创建 `smoke_*`、`results_*` 或其他平级结果目录。

统一结构：

```text
<method_root>/
├── results/
│   ├── <dataset>/<run_id>/        # 正式实验
│   ├── <experiment>/<dataset>/    # 需要单独命名的对照或消融
│   ├── _batches/                  # Python 多数据集汇总
│   ├── _launches/                 # Shell 启动配置、日志和总表
│   ├── _smoke/                    # 冒烟测试
│   └── _validation/               # 仅校验产生的记录
├── client/
├── server/
├── utils/
└── ...
```

当前约定：

- FSRIMVC V5 正式实验：`FRSIMVC-code/results/`
- FedRSMVC 30% 缺失基线：`FedRSMVC/results/baseline_mr30/`
- 冒烟测试：各方法自己的 `results/_smoke/`
- 路径校验：各方法自己的 `results/_validation/`

启动脚本中的 `OUTPUT_ROOT` 和配置文件中的 `result_path` 必须指向 `results/` 本身或其子目录。
