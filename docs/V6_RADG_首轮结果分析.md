调制明确生效，不能归因于开关未生效或近似恒等变换。节点平均可靠度约 Trento=0.693、MUUFL=0.709；corr(r,节点入射beta) 约 -0.987/-0.992，符合设计方向。

关键混杂：实验并非只比较固定0.5与“围绕0.5的自适应”，还同时把平均空间边权大幅降低。medium 实际约为0.29/0.28，strong约0.22/0.21。由此推测，整体空间图贡献减弱可能参与造成退化，但尚无匹配均值的固定权重对照，不能作因果结论。归一化后的实际消息贡献也不能简单等同于原始 beta 平均值。

corr(r,feature_edge_loss) 约 -0.936/-0.952，并不能独立证明 r 能预测语义可靠性：局部图本来就按 observed-mask 筛选，参考图也是受污染特征，只是取消该筛选。相关性部分由构图规则内生决定。

strong 的簇分布更均衡但 ACC 更低。例如 Trento 最大簇比例下降约0.058、簇熵增加约0.068、有效簇数增加约0.568；这再次说明集中度改善不自动等于聚类质量改善。

## 下一步建议

1. 优先补齐缺失的 5 jobs/10 runs，使用空闲 GPU，并保留原失败日志及批次归属；无需重跑全部成功项。本次仅检查分析，未启动补跑。
2. 若补齐后趋势保持，暂保留 fixed BSSAT-r1，不继续密集扫描 beta 上下界，也暂不进行 120-run 多缺失率验证或 completion。
3. 在决定 RADG-v2 前，优先区分“全局均值变化”与“局部自适应”：考虑在各视图上采用与 RADG 边权均值相同的常数融合，或围绕0.5中心化的 reliability 融合，以同批次 paired control 验证。该建议尚未实现/运行。
4. 不把当前负结果写成“observation ratio 完全无效”。当前被否定的是这组实现与参数在 random@0.3 下的收益，尚不足以否定更合理标定后的可靠性建模。
