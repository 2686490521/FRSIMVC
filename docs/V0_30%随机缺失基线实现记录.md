## 对照协议

- 数据集：Trento、MUUFL。
- 缺失模式：每个视图独立随机缺失超像素，目标比例 0.3。
- 约束修复：通过同一视图内安全交换消除所有视图同时缺失的节点，同时保持各视图目标缺失数。
- 输入：缺失超像素的中心块特征整行置 0。
- 图构造：使用原始 FedRSMVC KNN 图构造器处理 0 填充后的模态；不向图构造器提供观测掩码，不使用完整隐藏特征，不使用共享空间图。
- 损失：保持原始 FedRSMVC 重构损失，0 填充行同样参与训练；不使用 mask-aware loss。
- 聚类与融合：保持原始 K-means、客户端两两原型对齐和原始视图权重；不使用空间签名、Sinkhorn 或全局共识。
- 当前正式比较：seed 0–9，各 300 轮；其中 seed 0–7 可与已完成的 V5 30% 实验逐 seed 对齐。

## 一键运行

`run_datasets.sh` 当前默认配置为：

```bash
DATASETS=("Trento" "MUUFL")
START_SEED=0
N_SEEDS=10
EPOCHS=300
MISSING_RATE=0.3
GPUS=(0 1 2 3 4 5 6 7)
OUTPUT_ROOT="./results/baseline_mr30"
```

启动命令：

```bash
cd /home/ubuntu/Tangzl/FRSIMVC/baseline/FedRSMVC-main/FedRSMVC
bash run_datasets.sh
```

也可以显式指定本次只运行两个目标数据集：

```bash
bash run_datasets.sh Trento MUUFL
```

若只使用一张显卡，把脚本顶部改为 `GPUS=(0)`；脚本会自动依次运行全部 seed，无需修改其他变量。
