# v9 改动摘要与实施验收清单

更新日期：2026年9月22日。

详细规范见同目录《大纲v9_Completion实施与实验规范.md》。本次仅更新计划，未修改服务器代码、未启动实验、未移动或覆盖历史结果。

## 核心决定

冻结当前 F05+BSSAT-r1，关闭 RADG，首先实现不影响训练的 Completion 推理分支。原方法继续作为正式结果；候选通过全部六数据集的不退化与收益验收前不替换它。新模块的提升不能提前保证。

## 相对 v8 的具体更新

1. OT 质量耦合 Pi 与行条件映射 R 分开，原型按列质量做重心归一化，不直接使用 R 转置乘原型。
2. 增加同一模型时点的只读评估快照，避免 H、P、Pi 来自不同轮内阶段；单列 E0 测量刷新聚类头的影响。
3. 原始 B0、图填充 G0 和语义补全分开；lambda=0 是 G0，不再冒充原始 B0。
4. 增加 donor-only 的 D0，检查收益是否只是重复投票；所有候选使用相同有效覆盖权重。
5. 明确补全必须进入最终软标签融合；保留原 masked 融合时，仅修改缺失表示不能改变结果。
6. 伪缺失诊断排除特征图、原型与签名中的被隐藏信息；参考 latent 不称为真实 latent。
7. 全六数据集进入主实验；新增独立种子确认，不再只用 Trento 和 MUUFL 初筛。
8. 明确代码修改职责、配置覆盖顺序、GPU调度、结果目录、断点恢复与异常处理。
9. 把 Best ACC 标为 oracle-best-round，同时报告 Final、tail30 与同轮五指标。
10. 将 RADG 的否定结论限定于已测试方案，不扩大为所有可靠性方法无效。

## 实验规模

| 阶段 | 数据集与种子 | 训练轮数 | 独立训练轨迹 | 臂评估记录 |
| --- | --- | --- | --- | --- |
| 短测 | 全六数据集，seed 0 | 3 | 6 | 48 |
| 主实验 | 全六数据集，seeds 0至9 | 300 | 60 | 480 |
| 达标后确认 | 全六数据集，seeds 10至19 | 300 | 60 | 300 |

主实验八臂为 B0、E0、G0、D0、C025、C050、C075、C100。C050 为预注册主候选。所有臂共享基线训练，只做旁路评估；确认阶段使用冻结的一个公共 lambda。不要把480条评估记录写成480次独立训练。

固定 random@0.3、mask-before-SLIC、beta=0.5、epsilon=0.1、alpha=0、A3、dual、balanced、global_consensus=false、reliability_adaptive_graph=false。其余六数据集的路径、邻居数、superpixel数、优化器参数和 mask 行为详见主规范第11节。

## 实施验收清单

- [ ] 当前F05代码、配置、环境与历史结果完成冻结和哈希记录。
- [ ] 新功能默认关闭，关闭时输出与旧路径逐元素相同。
- [ ] 评估副本不改变训练模型、anchor、图、优化器及RNG。
- [ ] Pi与R的方向、质量归一化、零列回退均通过手算测试。
- [ ] donor排除自身，不循环使用补全预测。
- [ ] E0、G0、D0、四个C臂使用相同适配器快照与覆盖规则。
- [ ] 补全有效节点、预测改变率、无donor回退率均有日志。
- [ ] 伪缺失诊断不复用泄漏目标特征的kNN、原型或签名。
- [ ] 六数据集短测均完成；物理与逻辑GPU编号正确。
- [ ] 主实验60条轨迹、480条评估完整，逐轮五指标及可视化齐全。
- [ ] Best同轮、Final和tail30分开报告，不挑各指标峰值拼表。
- [ ] C与B0、G0、D0的逐seed差值及多重比较处理完整。
- [ ] 六数据集不退化门槛与独立确认通过后，才讨论替换正式方法。

## 实施顺序

冻结基线 → 关闭分支回归测试 → E0只读适配器 → G0与D0 → 重心投影与Completion → 伪缺失诊断 → 全数据集短测 → 主实验 → 结果分析 → 达标后确认。

代码实施重点为 `utils/csata.py`、`client/FedAvg_client.py`、新增 `utils/completion.py`、`Flsimulator.py`、图构建诊断接口、参数解析器、新增批量启动器和分析脚本。详细函数职责与测试见主规范第15至16节。

新结果统一保存在当前方法的 `results/completion_v1` 下，短测放 `results/completion_v1_smoke`；日志与汇总也留在方法内部，不再散落项目根目录。
