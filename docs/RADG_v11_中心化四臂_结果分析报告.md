> **中心化改造在机制上完全成功（E[β] 锁死在 0.5，Δ_A ≈ 0.20，干预真实存在），但性能上 C-RADG 没有超过固定融合 F05，反而在 5/6 数据集上小幅更差（pooled −0.0101, p=0.0017）。**

## 5. 剂量—反应：是否存在某个 γ 能救活 RADG？

这是决定"终止"还是"再调参"的关键。用**实际实现的干预幅度**（β_std / Δ_A）对**配对增益 ΔACC** 做回归：

| 层次 | 结果 |
|---|---|
| 数据集内（ΔACC ~ β_std，10 seeds） | 斜率 3 正 3 负，**全部不显著**（最小 p = 0.063）；斜率均值 +0.114，单样本 t 检验 **t=0.043, p=0.967** ⇒ 与 0 无法区分 |
| 数据集间（n=6） | r(ΔACC, β_std) = −0.361 (p=0.482)；r(ΔACC, Δ_A) = **−0.552** (p=0.256)；r(ΔACC, GT 类数) = +0.700 (p=0.121) |
| 全 60 run | r(ΔACC, Δ_A) = **−0.218** (p=0.094) |

**判读**：没有任何证据表明存在一个"干预幅度为正且带来增益"的工作点；斜率与 0 无差别，而 γ=0.5 处的均值已是 −0.0101。⇒ **不存在可搜索的正向 γ 区间**。若把 γ 调小，效应只会趋近 0（即退化成 F05），不会变正。

（一个值得记的弱信号：r(ΔACC, GT 类数) = +0.700，类数越多的数据集受损越小——Salinas 16 类是唯一正向的。但 n=6 不显著，不足以支撑"在细粒度数据集上保留 RADG"的分支。）

## 8. 验收判定（大纲 §24 / §32）

- 情况 A（接受）要求：**两个数据集都为正**，或**一个 > +0.01 且另一个 > −0.005** —— 都不满足（最好的是 Salinas +0.0029）。
- 情况 B（持平）例：Trento +0.002 / MUUFL −0.001 —— 我们的 pooled 不是持平，是**系统性小幅更差**（5/6 负、胜率 28.3%、二项 p=0.001）。
- 情况 C（终止）要求：C-RADG < F05 且趋势明确 —— **5/6 数据集为负、pooled 显著为负、Trento 显著为负、无可行 γ 工作点**，趋势明确。

### ⇒ 判定：**情况 C（偏 C 的 B/C 边界）——Module I（RADG）主线终止**

按 §32，不再做：扫 γ/上下界、加 semantic reliability（r_i + q_i）、加 attention、learnable β、多缺失率 ρ 扫描。**直接进入 Module III**。

正式论文框架确定为：

```
Mask-before-SLIC Setting
        ↓
      BSSAT
        ↓
Cross-Client Semantic-Spatial Completion (Module III)
```

## 9. 这个负结果怎么用到论文里（建议保留，别浪费）

1. **作为 design justification 写一小段**：我们系统验证了"基于节点观测率的局部图融合自适应"（含 mean-preserving 变体），在 6 数据集 × 10 seed 上**平均融合强度严格锁死**的前提下仍无增益（−0.0101, p=0.0017），因此最终方案**不采用**图层面的自适应，转而把建模预算投到跨客户端补全（Module III）。
2. **可直接引用的机制结论**：`F05 > F03`（+0.0120\*\*）说明**空间/语义等权融合已接近最优工作点**，任何偏离（全局下调或局部重分配）都要付出代价；而 `corr(r_i, β_node) = −0.99` 证明调制方向实现无误。⇒ 失败原因是**信号本身与图权重的最优分配不相关**，不是实现问题。这类"排除性实验"对 reviewer 是有说服力的。
3. **F05 即默认配置**：后续所有实验沿用 F05（β=0.5 固定融合，等价 A3+BSSAT-r1@ε=0.1），代码路径保持 `radg_mode` 可选但默认关闭语义（默认置为固定融合），不要删除实现（保留可复现性）。
